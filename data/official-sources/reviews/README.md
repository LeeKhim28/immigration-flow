# Source Reviews

Create one review note per source and review date when a source is promoted, disputed, or materially changed.

Suggested filename:

```text
YYYY-MM-DD__SOURCE-ID.md
```

Each review should record:

1. Reviewer and date
2. Source identity and issuing authority
3. Scope and intended user group
4. Effective or publication date, if stated
5. Material requirements observed
6. Conflicts with other official sources
7. Decision: candidate, reviewed, superseded, or retired
8. Follow-up date or trigger
